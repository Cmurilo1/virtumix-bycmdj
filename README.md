# VIRTUMIX BYCMDJ
Controladora DJ virtual no navegador — 2 decks, bateria eletrônica 4+4, MIDI global, waveform estilo VirtualDJ.

## Rodar local
Abra o `index.html` no Chrome ou Edge.

## Deploy na Vercel
Conecte este repositório na Vercel — sem build, é HTML puro.

## Requisitos
- Chrome ou Edge (Web MIDI + Web Audio)
- HTTPS (a Vercel já entrega)
